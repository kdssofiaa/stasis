# STASIS – HTML5 Canvas Mobile Game

A time-loop mobile game for Android, built as a single HTML5 canvas file for the UMPSA x Huawei GameCenter Mobile App Competition 2026 (Category B: Digital Mobile Games).

**Features:**
- 4-sector campaign with a time-loop storyline
- Endless mode
- Pause, mute and background music controls

**Tools:** HTML5 Canvas and JavaScript

**Play it:** https://fastidious-custard-64ad40.netlify.app

**How to run locally:** Download `[stasis].html` and open it in any browser. No installation is needed.
